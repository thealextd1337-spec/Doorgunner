# Sprites

Generated by `python tools/gen_sprites.py`. Do not hand-edit; regenerate instead. All RGBA, transparent background, facing UP unless noted.

Three art variants live in `a/` (RimWorld Classic), `b/` (Field Map) and `c/` (Grim Overcast), same file names in each.
Sizes below are LOGICAL; the PNGs are 4x that (tile 64 px, heli 128 px). Load them through `Art.sprite(name)` /
`Art.tex(name)` (scripts/art.gd), which picks the variant and scales by `Art.SCALE = 0.25`.
